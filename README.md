# mikebedar's Homebrew tap

## Hoot

[Hoot](https://github.com/mikebedar/Hoot) is a Safari extension that gives YouTube a calm, uncluttered watch page.

```bash
brew install --cask mikebedar/tap/hoot
open -a Hoot
```

Then turn Hoot on in **Safari → Settings → Extensions** and allow it on youtube.com.
Update with `brew upgrade --cask hoot`; remove with `brew uninstall --cask hoot`.
